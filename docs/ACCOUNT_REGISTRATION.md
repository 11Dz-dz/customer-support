# 用户自行注册（2026-11-02）

## 解决什么问题

原来只有管理员命令行创建账号，其他人测试前需要手动开通。现在登录页提供“注册账号”，用户自行设置用户名和密码，注册成功返回登录页，再使用原登录流程进入工作台。

## 使用方式

1. 打开现有工作台网址，点击“还没有账号？注册账号”。
2. 账号使用3–64位英文字母、数字、点、横线或下划线，大小写不区分。
3. 密码12–256字符，两次输入须一致；密码中的首尾空格保留。
4. 注册成功后回到登录页面，账号保留，密码框清空。

新账号可进行商品咨询、聊天与人工工单。新账号默认没有绑定订单客户，不能仅凭聊天输入客户编号访问订单。客户绑定仍由可信管理入口完成。注册接口不接受role、customer_id、active或display_name字段；角色固定user，客户编号固定为空。管理员开通原有客户账号的命令保持可用。

## 接口与限制

POST /api/auth/register：username、password、confirm_password。成功201，仅返回成功说明，不自动签发登录会话；重复账号409，输入不合法422，来源错误403，超过限制429。密码沿用scrypt加盐保存，不返回密码或哈希。Host和Origin沿用现有精确站点检查。

新增web_registration_limits表。每个服务器识别的客户端IP在15分钟内最多10次有效格式的注册尝试，全站同窗口最多60次。重复用户名也消耗次数；计数先单独提交，并用数据库事务锁处理并发，服务重启或更换WebStore不重置。超过一天的旧限流记录在后续注册时清理。转发来源只沿用服务器可信的request.client，不自行信任浏览器伪造的X-Forwarded-For。

SSH隧道或共享代理可能使多名测试者表现为同一IP，因此会共享该IP额度。公开部署需要先正确配置可信代理；不应为绕过限流直接信任任意转发头。注册请求格式不合法时不执行密码哈希，也不创建用户。

## 修改文件

- webapp/api.py：注册数据校验及公开注册接口。
- webapp/store.py：限流、固定普通用户/未绑定客户、重复账号错误转换。
- schema_web.sql：可重复执行的新限流表创建。
- frontend/src/App.vue：登录/注册切换、确认密码与注册成功提示。
- frontend/src/style.css：注册入口和提示布局。
- tests/test_web.py：注册、权限、唯一性并发、限流及输入边界测试。

本轮没有增加邮箱/手机验证、忘记密码、自助客户身份绑定或付款退款能力。该功能不改变Agent规划、检索与回答逻辑，不将之前M01、P09评测失败改判为通过。
