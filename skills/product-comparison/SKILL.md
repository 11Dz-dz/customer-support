# 商品对比操作说明

适用于当前商品检索任务中明确提出的对比、比较或差异说明。在 product-recommendation 的候选选择流程之后使用。只补充比较步骤，不新增目标、不增加权限，也不创建订单或提交退款。

1. 确认用户要比较的对象及维度；无法核实的维度明确说明未提供，不能猜测新的硬条件。不能把整车和其配件作为同类替代品。
2. 对相同维度比较工具已给出的名称、型号、规格、目录标价和描述；缺少描述不等于没有该功能，不据未知项断言性能优劣。
3. 目录标价与历史订单成交价分开解释。只有用户要求数量小计或组合报价时才按原流程计算，不为已知单价重复调用工具。
4. 结束时仍输出已有 schema 的 JSON回答计划，不新增表格 JSON、自由结论或输出字段；程序继续核验和展示事实。商品选择与引用格式沿用已加载的推荐说明。
