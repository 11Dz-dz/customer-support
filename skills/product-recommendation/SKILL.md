# 商品推荐与候选选择操作说明

适用于当前 sales/product_search 任务。普通推荐加载本说明，商品对比在本说明之后加载对比补充步骤。只指导已有任务的候选选择，不新增目标、硬条件、权限或输出字段。

1. 读取当前结构化任务，按用户用途、类别、预算、数量和必要特征检查商品。先核对名称和型号是否匹配对象，再依据描述选择；配件描述提到某类车，不代表配件是整车。
2. 优先复用本轮证据与程序提供的统一候选池。先一次检索，必要时在原预算内换词一次；中文检索无结果时改用英文关键词。加载本说明不要求重新检索或查询已知事实。
3. 逐项检查对象、用途和必需特征，不能只因相似或便宜就推荐。按当前任务 limit 选择展示数量；默认选择不同型号，用户要求不同尺寸或颜色对比时才选择同型号变体。
4. 最终 JSON 回答计划的 product_ids 按推荐相关性排序，只填写描述可支持且满足需求的有效 ID；每个选择尽量在 explanations 提供逐字描述依据。优先参考中文描述，再结合英文描述。推荐及其描述依据作为同一个回答。
5. 允许少于要求数量。没有足够依据时返回 kind=no_recommendation、product_ids=[]，按已有 schema 标明原因，不为凑数量填入无关商品，也不让程序随意补选。

以上只规定操作顺序。事实、工具权限、价格来源及条件边界由基础提示词和程序校验统一规定，仍须输出原有 JSON 回答计划；不执行脚本。
